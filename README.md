# mattcandler-assets

Drawings for the head unit on mattcandler.io, served via jsDelivr:
`https://cdn.jsdelivr.net/gh/mcandler/mattcandler-assets@main/headunit/<file>`

To update a drawing, add it with a new version number (e.g. `desk-v2.svg`)
and change the file name in the snippet, so no one sees a cached old copy.
